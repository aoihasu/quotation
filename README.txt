AVON FOOTWEAR MACHINES — QUOTATION

Files:
- index.html  -> quotation structure/content
- style.css   -> all visual styling and print/A4 page-break rules
- script.js   -> quotation calculations, rows, form handling, and auto-growing fields

Keep all three files in the same folder.
Open index.html in Chrome/Edge.

The logo is embedded in index.html, so no separate image file is required.
