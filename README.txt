AVON FOOTWEAR MACHINES - QUOTATION

Files (keep in one folder):
- index.html -> structure
- style.css  -> styling and A4 print rules
- script.js  -> quotations, products & prices, sent tracking, Excel export
- logo.jpg   -> logo

Open index.html in Chrome/Edge. With no server, data is saved in the browser (use Export to Excel / Backup regularly).
Excel export needs internet once per export (SheetJS from cdnjs); otherwise it saves a CSV.
